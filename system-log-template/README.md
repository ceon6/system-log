# system-log-template

사내 자동화 프로그램의 **시스템 로그(구축 및 버전 명세서)** 양식과 AI 작성 지침.

| 파일 | 용도 |
|---|---|
| `TEMPLATE.md` | 빈 양식. 사람이 직접 채울 때 사용 |
| `PROMPT.md` | AI가 이 양식으로 로그를 작성·갱신할 때 따르는 지침 |

## 사용법

AI에게 이 저장소 링크와 대상 자료를 함께 주고 요청한다.

**신규 작성**
```
{이 저장소 링크} 의 PROMPT.md 지침과 TEMPLATE.md 양식으로
{프로그램명} 시스템 로그 새로 작성해줘.
근거 자료: {코드 repo 링크 / 대화 / 파일}
출력: {노션 업무관리 DB 페이지 | repo의 SYSTEM_LOG.md}
```

**버전 추가**
```
{이 저장소 링크} 지침대로 {기존 로그 링크}에 이번 변경을 새 버전으로 추가해줘.
변경 내용: {요약 또는 커밋·대화 링크}
```

## 양식 구성

1. 머리 인용 — 문서 상태 / 최종 수정일 / 작성자 / 대상 범위
2. 시스템 기능 및 아키텍처 개요 — 핵심 기능, 데이터 흐름, 구성 요소
3. 핵심 비즈니스 로직 & 운영 표준 — 구분 / 산식·기준 / 시스템 반영 방식
4. Version History — `v1.0.0` 설계~테스트, `v2.0.0` 정식 운영, 이후는 토글

## 주의

- 로그에 API 키·토큰·고객 실명·금액을 넣지 않는다 (`PROMPT.md` 6항).
- 저장소를 공개(public)로 둘 경우, 실제 운영 로그는 이 저장소가 아니라 각 프로그램 저장소(비공개)나 노션에 둔다.
